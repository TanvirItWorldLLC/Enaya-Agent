# Enaya Agent Platform Enaya is a full-stack autonomous agent platform that learns, remembers, and extends indefinitely. ## Features - **Autonomous Agent Core**: Goal-oriented task planning and execution - **Memory System**: Short-term context + long-term vector memory - **Skills Framework**: Learn, store, and reuse capabilities - **Gateway**: WebSocket + HTTP + MCP unified access layer - **Multi-Backend**: 6 terminal backends (local, docker, ssh, subprocess, kubernetes, cloud) - **Plugin Architecture**: Extensible via plugins and MCP servers - **Multiple Surfaces**: CLI, TUI, ACP adapter, WebSocket gateway ## Quick Start ```bash pip install enaya-agent enaya --help enaya chat # Interactive TUI enaya run --task 'Deploy a static site to S3' # Autonomous execution ``` ## Project Structure ``` enaya/ ├── agent/ # Core agent orchestration ├── tools/ # Tool framework and built-in tools ├── gateway/ # WebSocket/HTTP/MCP gateway ├── plugins/ # Plugin system ├── ui-tui/ # Terminal UI ├── acp_adapter/ # Agent Communication Protocol ├── tui_gateway/ # TUI-based gateway ├── backends/ # Terminal backends ├── tests/ # Comprehensive test suite └── docs/ # Documentation ``` ## Architecture Enaya follows a modular architecture: 1. **Agent Core** manages state, planning, and execution loops 2. **Memory Layer** provides embedding-based retrieval 3. **Tool Registry** discovers and executes capabilities 4. **Gateway** exposes unified API surfaces 5. **Backends** abstract execution environments 6. **Plugins** extend functionality dynamically ## License MIT
